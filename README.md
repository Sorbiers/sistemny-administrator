# Системный Администратор

Роман Андрея Сорбье «Системный Администратор» (в соавторстве с моделями Claude) — роман в двух мирах:
офисная Москва 2001–2004 годов и мир, куда герой попадает во сне и где ему постепенно открывается всё.

**Текста романа и аудиоверсии в этом репозитории нет.** Здесь рабочие материалы автора и инструменты,
которыми из глав (`chapters/NN.md`) собираются сайт для чтения и аудиокнига.

## Материалы

| файл | что это |
| --- | --- |
| [`synopsis.md`](synopsis.md) | синопсис: сюжет целиком, структура частей и глав, решения автора (**спойлеры**) |
| [`characters.md`](characters.md) | библия персонажей обоих миров |
| [`worlds.md`](worlds.md) | библия мира: Москва 2000-х и мир сна, правила, словарь, хронология событий |

## Инструменты

| файл | что делает |
| --- | --- |
| `build_site.py` | главы → `site/index.html` (одна страница: оглавление, темы, позиция чтения, иллюстрации) и подстраницы: аудиокнига, синопсис, библии, «О проекте» |
| `build_audio.py` | главы → `site/audio/NN.mp3` через русский TTS из [Gogolium](https://github.com/Sorbiers/gogolium) (Silero `v4_ru`, голос eugene); кэш по абзацам |
| `gogol_ssml.js` | готовит SSML функциями Gogolium: числа словами, словарь ударений, паузы |
| `stress.json` | ударения в омографах: по умолчанию для слова и исключения по контексту |
| `audiobook.py` | главы → один MP3 с оглавлением (ID3 CHAP/CTOC), без внешних библиотек |
| `serve_site.bat` | пересобрать сайт и открыть его на `http://127.0.0.1:8765/` |
| `audio.bat` | озвучить все главы (или `audio 2-5`) и пересобрать сайт |

Нужно: Python 3.11+, пакет `markdown` (страницы синопсиса и библий), Pillow (необязательно — уменьшение
иллюстраций). Для озвучки — [Gogolium](https://github.com/Sorbiers/gogolium) с настроенным `app\tts`
(путь — переменная `GOGOL_DIR`), Node.js, FFmpeg/ffprobe.
